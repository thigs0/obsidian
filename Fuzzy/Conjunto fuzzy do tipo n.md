**Definição:**
Seja U um universo de discurso. Um [[conjunto fuzzy]] A do tipo 1 de U é caracterizado por uma [[Função de pertinencia]] $\varphi_A:U \to [0,1]$ que associa a cada elemento $u\in U$ um valor $\varphi_A(u)$ no intervalo

De maneira simples: Um conjunto fuzzy do tipo n de U, em que n é um [[Inteiro]] maior que 1, e é associado recursivamente

- Toda família do tipo um é um [[reticulado completo]] no intervalo [0,1]
$$A\subset_1 B\Leftrightarrow \varphi_A(u)\leq_{\mathbb{R}}\varphi_B(u)$$
- tipo dois não é um reticulado completo


#### Redução de tipo
- Um método de redução de tipo é uma aplicação que leva um [[conjunto fuzzy]] do tipo n para um [[conjunto fuzzy]] do tipo $n-1$
- [[Defuzzificação]] é um método de redução de ordem
