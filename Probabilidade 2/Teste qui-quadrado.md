- Teste criado para encontrar associação entre dois valores que são [[Variável Aleatória]]s qualitativas
- É um teste [[não paramétrico]]
- [[Hipótese Nula]]$(H_0)$ -> frequência observada = frequência esperada. Não há associação entre os grupos
- [[Hipótese alternativa]]$(X_0)$ -> As frequências observadas $\neq$ frequências esperadas. Os grupos não são associados
- Nível de significância $\alpha$: Significa o risco de se rejeitar uma hipótese verdadeira. Deverá ser estabelecido antes da análise de dados e é usualmente fixado em $5\%$
- [[Graus de Liberdade qui-quadrado]]: é a diferença entre o número de classes resultados e o número de informações da amostra que são necessários ao cálculo dos valores esperados nessa classe

**Condições**
- Os grupos devem ter [[Independência]]
- Os itens de cada grupo são selecionados aleatoriamente
- As observações devem ser frequência ou contagens

$$\chi^2=\sum\limits_{i=0}^n \frac{(f_{observada}-f_{esperada})^2 }{f_{esperada}},~~~\text{f é a frequência}$$
