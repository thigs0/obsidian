Seja $Y\subset X \subset \mathbb{R}$ é denso em X se todo ponto aderente de Y é ponto de X


#### Teorema
Todo [[Conjunto]] $X\subset \mathbb{R}$ contém um conjunto enumerável e denso em X
**Dem**:
Para cada $n\in \mathbb{N}$, seja $\mathbb{R}=\cup_{p\in \mathbb{I}}\left[ \frac{p}{n},\frac{p+1}{n} \right[$
para cada $n\in \mathbb{N}$ e $p\in\mathbb{Z}$, $x_n\in X_n\cap \left[\frac{p}{n},\frac{p+1}{n}\right[$ caso x exista
$E=\{x_{pn} :~ p\in\mathbb{Z}, n\in\mathbb{N} \}$ é enumerável, pois $\mathbb{Z}\times \mathbb{N}$ é enumerável. Falta mostrar que E é denso em X.
